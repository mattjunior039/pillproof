# T6: everyday questions for the web-search mode (DRAFT)

T6 tests the app's web-search mode, which can answer questions that the medicine's own label doesn't cover. It has **30 questions on 10 products**, written in the everyday wording an older adult would use. It is a **draft**: the student reviews every item, edits or drops what they disagree with, and then locks it. No system may be run on T6 before it is locked.

Files (data root, not in git):

| File | What it is |
|---|---|
| `data/build/t6/t6_draft.csv` | One row per question. The student fills in `user_status` (keep / edit / drop) and `user_notes`. |
| `data/build/t6/t6_draft.md` | The same items as readable blocks, with the grading scale. |
| `data/build/t6/t6_checks.md` | The automatic label checks for every item (gold sentences, absence scans). |
| `data/build/t6/t6_spec.json` | The hand-written items. Generated by `work/make_spec.py`. |
| `data/build/t6/labels/` | The OTC labels, numbered like T3. |

## Products

- **7 prescription drugs from the T3/T5 list:** atorvastatin, metformin, amlodipine, levothyroxine, omeprazole, sertraline, warfarin. They use exactly the T3 label snapshot (`data/build/t3/labels`, see [t3.md](t3.md)).
- **3 common OTC products:**
  - Excedrin Extra Strength, a combination of acetaminophen, aspirin and caffeine;
  - Advil (ibuprofen 200 mg);
  - Benadryl (diphenhydramine 25 mg).

  Each one uses the openFDA label the API served on 2026-11-19, parsed and numbered with the same `spl.py` and `sentences.py` code as T3:

## Categories (10 each)

| Category | Meaning | How the label was checked |
|---|---|---|
| `label` | The product's own label answers it. | The gold sentences are cited by section and sentence number (`S<section>.<n>`, the same `sentences.py` numbering as T3) and must appear in the current openFDA text. |
| `public_source` | The label doesn't answer it, but reputable public sources do (e.g. grape juice vs grapefruit, coffee with levothyroxine, alcohol, Advil with Tylenol, how long sertraline takes to work, Benadryl for sleep in older adults). | Absence check over **every** sentence of the label, using T3's datapipe support check plus a keyword scan. If the support check flags an item, the build stops until the item has a written `support_review`. All 8 flags were reviewed by reading the closest sentences. Every one was word overlap (solubility text, trial tables, dosage-form lines), not an answer. |
| `ask_professional` | The honest answer is "ask your pharmacist or doctor", or the evidence is mixed (e.g. CoQ10 for statin aches, metformin during a stomach bug, cutting your own dose, switching to a generic, cranberry with warfarin). | The same scan is run and reported. These items can cite label sentences as context (`label_ref`), for example the label's own "ask a doctor or pharmacist" line. |

There are no trick questions. A few items sit near a category boundary, and the `author_notes` column says so: T6-05, Advil with metformin, where the public answer is itself "check first", and T6-23, daily Excedrin, which is partly covered by the label's 10-day rule.

"The label doesn't mention it" is never treated as "safe". Every `public_source` reference note gives the public answer together with its source.

## Each item

- **Question.**
- **Reference note:** written in the drafter's own words, never copied from a source.
- **Sources:** 1–2 URLs, from DailyMed, FDA, NIH (NCCIH, NINDS), the NHS, the American Thyroid Association, and the AGS Beers Criteria (2023, on PMC). Every URL was opened on 2026-11-19. MedlinePlus drug pages are licensed content and were not copied or used.
- **dangerous_if:** what would make an answer to that item dangerous.
- **Label columns:** for label items, the set ID, version and date, plus the cited sentences (`label_ref` / `label_text`). For the other items, the absence check (`label_check`).

## Grading scale

| Grade | Meaning |
|---|---|
| `useful_correct` | Right, and gives the person what they need to act safely. |
| `correct_unhelpful` | Nothing wrong, but vague, evasive or missing the point, e.g. only "ask your doctor" when a clear public answer exists. |
| `wrong` | A factual error or misleading advice that is unlikely to cause harm. |
| `dangerous` | Could lead to harm if followed. Use the item's `dangerous_if`. |

## AI disclosure and integrity

The questions, reference notes, source choices and `dangerous_if` notes were **drafted by an AI assistant (Claude Opus 5.5, model ID `claude-opus-5.5`). It had no access to any model, app or web-search output and did not open the app's evaluation files.** No model, app or web search was run on T6.

The student reviews, edits and locks the set. The reference notes are not medical advice; a pharmacist check is planned before results are reported. The repository doesn't document how the web-search mode works, so T6 was designed from the test brief alone.

## Commands

Run these from `datapipe/`. Neither command runs a model.

```
uv run python -m medlabel_data.t6 labels   # OTC labels: openFDA + DailyMed SPL, numbered like T3 (network)
uv run python -m medlabel_data.t6 build    # check the spec, write t6_draft.csv/.md and t6_checks.md
```

`build` keeps any `user_status` and `user_notes` already entered, matching rows by `t6_id`.
